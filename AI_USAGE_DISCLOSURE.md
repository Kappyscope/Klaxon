# AI USAGE DISCLOSURE

In order to be transparent as much as possible, this project was made with the assistance of artificial intelligence large-language model technologies hosted on a mixture of being made locally on a computer and outsourced partially to API keys or tools. Generative AI tools were used for the following actions:

-Generating graphical branding assets (i.e., the logo font which cannot be found)

-Writing parts of code

-Debugging parts of code

-Reworking important functions of code

-Checking parts or segments of code

-Testing specific features contained in the code

-Assistance in porting systems to allow functions to work
